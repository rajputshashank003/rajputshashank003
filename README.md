## Featured Projects

### [ChessV](https://github.com/rajputshashank003/Chess.v.0.2.1) · [Live](https://chessv.netlify.app/)
Real-time multiplayer chess platform with live spectating, P2P voice/video chat, custom match creation, and move-by-move state sync over WebSockets. Includes a 3D landing page and Solana-based betting.
`React` `Socket.io` `WebRTC` `Solana`

### [CostOp](https://costop.in)
A SaaS spend-optimization platform that helps businesses track every software subscription, surface unused licenses, and automatically cut wasted spend. Built as a subscription-based product with a Go backend and PostgreSQL, paired with a React frontend for spend analytics dashboards.
`Go` `PostgreSQL` `React`

### [Aiksava](https://aiksava.costop.in)
Full-stack e-commerce platform covering the complete order lifecycle — browsing, cart, checkout, and tracking. Payments run through a dedicated Go microservice with idempotent, event-driven processing, plus automated shipment creation via the Shiprocket API.
`MERN` `Go` `Docker` `Redis` `BullMQ`
